What This Shows

The gallery is the human-facing layer over the JSON spec. Pick a category first, then a recipe. Each recipe carries a recipe-faithful Gemini prompt and a ChatGPT prompt (override or Gemini fallback) -- no global photorealistic wrapper.

Provider Comparison

The image strip on each card shows the same recipe rendered by different providers (Codex, Ark/Seedream, Gemini, ChatGPT) where example assets exist. The recommended_providers chips list which backends suit the recipe.
